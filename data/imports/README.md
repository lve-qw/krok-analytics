# Входные выгрузки

Для готового демонстрационного набора эта папка не нужна — из корня репозитория
достаточно выполнить:

```bash
./run_dashboard.sh
```

Сюда нужно класть данные только для запуска на другой выгрузке. Каждую выгрузку
храните в отдельной папке:

```text
data/imports/
└── current/
    ├── dialogs.csv
    └── use_cases.csv
```

Нужны именно два файла, которые создаёт существующий pipeline:

- `dialogs.csv` — по одной строке на диалог;
- `use_cases.csv` — соответствие `request_id` сценарию использования.

`analytics.csv` сюда класть не нужно: это legacy-результат pipeline, адаптер его
не читает и не перезаписывает.

Затем из корня репозитория выполните:

```bash
./run_dashboard.sh data/imports/current
```

Канонический файл, отчёт адаптера и ошибки будут созданы в `outputs/`. Эта папка,
как и содержимое `data/imports/`, исключена из Git: реальные логи не должны
случайно попасть в коммит.

Выгрузка должна использовать 31 официальный класс из `data/classes_31.csv`.
`scenario_id` и классы из `data/classes.csv` — legacy/demo-метаданные и не
заменяют итоговые `class_ids`/`class_names`.
